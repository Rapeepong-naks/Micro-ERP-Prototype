# ระยะแรกเน้นระบบสต็อก ยังไม่เชื่อมต่อกับ LINE

เคยพิจารณาให้ร้านย้ายการสั่งซื้อไปที่ LINE OA เพื่อให้บอตอ่านและตรวจสลิปได้อัตโนมัติ แต่ตัดสินใจว่าระยะแรกจะยังไม่ทำส่วนที่ต้องเชื่อมต่อกับ LINE และเน้นระบบสต็อกก่อน เหตุผลคือร้านในกลุ่มเป้าหมายไม่ได้ซื้อขายผ่าน LINE ทุกร้าน การขายผ่าน LINE เป็นพฤติกรรมของร้านนำร่องร้านเดียว ส่วนการส่งบิลและการตรวจสลิปจะเป็นระบบแยกที่ค่อยพิจารณาทีหลัง

## Consequences

ในระยะแรก ร้านยังรับคำสั่งซื้อและตรวจสลิปผ่าน LINE ด้วยมือเหมือนเดิม ระบบรู้เรื่องการขายผ่าน LINE ได้ก็ต่อเมื่อเจ้าของร้านบันทึกเองเท่านั้น
