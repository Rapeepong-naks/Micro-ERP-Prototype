# Khonnai: ตรวจทาน flow กับรายงาน UX ฉบับแก้ไข

ตรวจเมื่อ 27 ตุลาคม 2026 โดยเทียบ `Khonnai-UX-Flow-Review-Revised (1).docx` กับ `prototype/` และเว็บทดสอบ `dist/user-test-site/`. รายงาน Word ตรวจแอป React อีกชุดหนึ่ง จึงใช้เป็นรายการปัญหาและโจทย์ธุรกิจ ไม่ถือว่าผลทดสอบในรายงานยืนยันสถานะของ HTML prototype นี้ สถานะด้านล่างอ้างอิงโค้ดและ smoke test ของ prototype ปัจจุบัน

## หลักที่ใช้ปรับ UI

- ใช้ภาพเส้นของสินค้าตามประเภทเป็น placeholder ที่เป็นองค์ประกอบ HTML/SVG จริง พร้อมรหัส รุ่น ราคา และยอดที่ขายได้; ภาพสินค้าจริงยังต้องได้จากร้าน
- ใช้ Soft Azure น้ำเงิน `#3878DB` สำหรับการกระทำหลัก และส้ม `#F99545` สำหรับจุดเน้นหมวดสินค้า/หัวข้อ/ยอด โดยยังคงตัวอักษรไทยและ wordmark เดิม
- แสดงหมวดและหมวดย่อยก่อนชื่อรุ่นเพื่อลดการกวาดสายตาในรายการยาว; ที่ POS ยังคงค้นหาและตะกร้าเป็นแกนหลัก
- ใช้การขยายรายละเอียดทีละไซซ์ในฟอร์มสต็อก เพื่อไม่ให้ 15–30 ช่องปรากฏพร้อมกันตลอดเวลา

การตัดสินใจนี้เป็นการสังเคราะห์จาก [Shopify POS: product search](https://help.shopify.com/en/manual/sell-in-person/shopify-pos/inventory-management/searching-for-products), [Square Retail POS: customer cart](https://squareup.com/help/gb/en/article/8238-build-your-customer-s-cart-in-the-square-retail-pos-app), [Loyverse: item variants](https://help.loyverse.com/help/how-use-variants-items), [UNIQLO: bra tops](https://www.uniqlo.com/th/en/women/tops/bra-tops?path=%2C%2C39240), และ [Shopify Dawn](https://themes.shopify.com/themes/dawn/presets/dawn?locale=us). ไม่ได้คัดลอกหน้าจอของผู้ให้บริการเหล่านี้

## ลำดับทดสอบรอบถัดไป

1. ให้เจ้าของร้าน 3–5 คนออกบิล 20 รายการจาก 100 รุ่น จับเวลาและนับการย้อน/เลือกผิด; เกณฑ์เป้าหมาย 10 นาที
2. ให้สร้างรุ่น 3 ไซซ์ × 5 สี โดยมีสองคู่ที่ไม่มีจริง และสต็อกบางคู่เป็นศูนย์; ตรวจว่าผู้ใช้ไม่สับสนระหว่างไม่มีแบบกับของหมด
3. ให้รับของเข้า 20 รุ่นในใบเดียว โดยค้นหารุ่นกลับไปกลับมา; วัดจำนวนครั้งที่ต้องเลื่อนและเวลาจบงาน
4. ให้จอง → ขาย → เปิดบิล → กลับรายการจอง และเลิกขายรุ่นที่มี/ไม่มีการจองค้าง; ตรวจว่าผู้ใช้ทำนายผลต่อสต็อกได้
5. สัมภาษณ์เรื่องราคาแยกไซซ์/สี, ราคาพิเศษ, การพักบิล และหน่วยขาย ก่อนออกแบบข้อมูลจริง

`prototype/smoke-check.cjs` ตรวจ state transitions; `prototype/qa/browser-smoke.cjs` ตรวจ flow ใน Chrome. ทั้งสองเป็นการตรวจทางเทคนิค ยังแทนการทดสอบผู้ใช้จริงไม่ได้
